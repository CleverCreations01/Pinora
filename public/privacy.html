PINVORA Privacy Policy

Last updated: November 14, 2026

PINVORA is a Pinterest content-planning application. This policy explains what information the application processes, why it is used, where it is stored, and how users can disconnect or clear it.

1. Information PINVORA processes

  • Pinterest connection data: when a user chooses to connect Pinterest, PINVORA receives OAuth tokens and the permissions approved by that user. The app uses these tokens to check connection status, read the user's boards and, when enabled, create Pins after the user explicitly requests the action.
  • Pinterest content: board names and IDs, Pin fields and API responses are processed only when the user requests the related feature.
  • Workspace data: campaign prompts, generated Pin drafts, selected Pins, product records, affiliate tracking IDs, preferences and user-selected images are stored in browser local storage on that device.
  • Essential session cookies: PINVORA uses an HttpOnly session cookie to associate a browser with its own encrypted Pinterest connection, and short-lived HttpOnly cookies to validate the OAuth callback and protect against request forgery.

PINVORA does not ask users for their Pinterest password or Pinterest browser-session cookies. It does not intentionally collect device contacts or precise location.

2. Where information is stored

Workspace data, including uploaded image data saved with drafts, remains in the user's browser local storage. It is not uploaded as a shared PINVORA profile. Anyone with access to the same unlocked browser profile may be able to access that browser's local workspace, so users should protect their device and browser profile.

Pinterest access and refresh tokens are encrypted server-side using AES-256-GCM before being written to a private Vercel Blob store. Token records are associated with a random browser-session identifier. Pinterest credentials and encryption keys are kept in server-side environment variables and are not included in the public client bundle.

3. How information is used

Information is used to provide the feature the user requests, including displaying the user's own Pinterest boards and preparing or creating Pins. PINVORA does not sell personal information. PINVORA does not publish, create or modify Pinterest content without a user-initiated action and confirmation.

4. Service providers and sharing

Pinterest processes information when the user authorizes the connection or requests a Pinterest API action. Vercel provides application hosting and private Blob storage. These providers process information under their own terms and privacy policies. PINVORA does not share browser workspace data with other PINVORA users.

5. Retention, disconnecting and deletion

Users can choose Disconnect Pinterest and delete connection data in PINVORA. This removes the encrypted Pinterest token records associated with that browser session and clears the session cookies. It does not delete Pins or boards already created in Pinterest and does not itself revoke the app in Pinterest's account settings; users can also revoke PINVORA from their Pinterest connected-app settings.

Users can choose Clear this device's PINVORA workspace to remove the saved drafts, Pins, product list, preferences and Amazon Associates tracking ID from that browser. Clearing browser site data also removes local workspace data. This does not delete content already published to Pinterest.

When a user disconnects, the associated server-side token records are deleted from PINVORA's private Blob store. Deletion from provider backups or caches may follow the provider's documented retention periods.

6. Security

PINVORA uses HTTPS, HttpOnly session cookies, OAuth state validation, session-scoped token access, encrypted token storage and server-side secrets. No online service can guarantee absolute security; users should keep their devices and accounts secure and report suspected unauthorised access.

7. Children's privacy

PINVORA is not designed for children under 13 and does not knowingly collect personal information from children under 13.

8. Privacy contact

A dedicated privacy contact email must be added by the operator before PINVORA is opened to general users. For now, users can disconnect PINVORA in the app and revoke access from their Pinterest connected-app settings. This contact section is not yet complete for public launch.

9. Policy updates

This policy may be updated when the application's features or data practices change. The latest effective date appears at the top of this page.
