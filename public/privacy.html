PINVORA Privacy Policy

Last updated: November 13, 2026

PINVORA is a Pinterest content planning application. This policy explains what the current application does and does not collect.

1. Information processed

PINVORA does not ask for a Pinterest password, session cookies, device contacts, location, photos library access, or files outside the images a user deliberately selects. If a user chooses to connect Pinterest, Pinterest OAuth returns permissions and tokens approved by that user. Depending on the feature used, PINVORA may process board names and identifiers, Pin content and publishing responses.

Campaign drafts, selected Pins, affiliate tracking IDs and preferences are stored in that user's browser local storage. They are not uploaded as a workspace profile or made visible to other PINVORA visitors. Images selected for a Pin are held in that browser until the user chooses a publishing workflow.

2. Account isolation

Pinterest OAuth credentials are stored server-side in encrypted private storage, separately for each browser session. API requests use only the token associated with the session cookie presented by that browser. A visitor without a connected session cannot read another visitor's connection status, boards or publish on their behalf. Legacy shared token records are not used by the current application code.

3. How information is used

Information is used only to provide the feature the user requests, such as showing their Pinterest boards or publishing a Pin after explicit action. PINVORA does not sell personal information and does not run advertising or cross-site behavioural tracking in this build.

4. Security and third parties

Pinterest tokens are encrypted with AES-256-GCM before being written to private Vercel Blob storage. Application secrets remain in server environment variables. Pinterest receives information required to complete the OAuth or API action requested by the user. Vercel provides application hosting and private storage under its own terms and privacy policy.

5. Retention and deletion

Browser workspace data remains in that browser until the user clears the site's data. Server-side Pinterest tokens remain while the connection is active. Users can revoke PINVORA's access in their Pinterest account's connected-app settings. Revocation prevents future authorised actions; the related server token record should also be deleted by the service operator as part of a deletion request.

6. Contact and privacy requests

This public review build does not publish an individual operator's personal email address or phone number. For account access concerns, users can revoke PINVORA from Pinterest's connected-app settings. A dedicated privacy contact channel should be supplied by the operator before the service is opened to general users.

7. Children's privacy

PINVORA is not designed for children under 13.

8. Changes

This policy may be updated when the application's features or data practices change. The latest effective date appears at the top of this page.
