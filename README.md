# PINVORA

Mobile-first Pinterest content planning studio.

Current capabilities:
- Campaign draft generation and local workspace persistence.
- Pinterest OAuth Authorization Code flow on the canonical production origin.
- Encrypted, session-isolated Pinterest token storage.
- Live Pinterest board retrieval for the connected user.
- Production Pin creation and board creation endpoints remain gated until Pinterest Standard Access is approved and explicitly enabled.

See [Pinterest Standard Access readiness](./PINTEREST_STANDARD_ACCESS.md) for the OAuth configuration, publishing safety gate, and review checklist.
